# ChipBoy demo

A sixteen-bar tune at 120 BPM that plays all four channels and automates the
parameters, generated by `tools/demo/make_demo.py` (standard-library Python; two runs
give byte-identical files).

| File | What it is |
|---|---|
| `ChipBoy Demo.rpp` | A Reaper project: one track with the ChipBoy VST3, the tune as a MIDI item, and automation envelopes. |
| `chipboy_demo.mid` | The same tune as a Standard MIDI File, one track per hardware channel on MIDI channels 1–4. For any host. |
| `PARAMETERS.md` | ChipBoy's host-visible parameters in index order, with the normalised values Reaper stores and the VST3 parameter ids. |

## What it plays

| Bars | PU1 (channel 1) | PU2 (channel 2) | WAV (channel 3) | NOI (channel 4) |
|---|---|---|---|---|
| 1–4 | Square lead, the theme | Pluck bass, velocity accents | Triangle bass | Kick, snare, hats |
| 5–8 | The theme with mod-wheel vibrato (CC1 rises, holds, falls) | Bass | Tri-to-saw wave (frames) | Beat, open hat on the offbeats |
| 9–12 | Eighth notes; the duty changes per bar through automation | Envelope rate automated | Triangle bass, frame automation | Beat with a crash |
| 13–16 | Pitch bends; the model switches DMG → CGB → RAW over the last bars | Bass | Organ frames | Fill; de-click toggled for the last bar |

The chords are A minor, F, C, G. Drums change instrument through **keyswitches**: the
noise channel's keyswitch octave is MIDI notes 12–23 (the wave channel's too; pulse
channels use 24–35), and note 12 + slot − 1 selects factory slot *slot* without
sounding. The envelopes turn `ch4_keyswitch` and `ch3_keyswitch` on and set
`ch1_source` to *MIDI 1* so PU1 stops answering every channel.

## Reaper

Open `ChipBoy Demo.rpp` with the ChipBoy VST3 installed (see the README's build
section). If Reaper shows the plugin offline, insert *VST3i: ChipBoy (ChipBoy)* on the
track by hand; the envelopes stay attached by parameter index, which is the plugin's
add order and does not change between builds of the same version.

## FL Studio and other hosts

Drop `chipboy_demo.mid` onto a new pattern (FL: File → Import → MIDI file, or drag it
onto the channel rack). Put one ChipBoy instance in the channel rack and give the four
imported MIDI tracks channels 1–4 (FL: the channel's MIDI channel in its settings, or
the pattern's per-channel port). Then in the plugin:

- set PU1's source to *MIDI 1* (its default is omni),
- turn **Keyswitches** on for the WAV and NOI channels (in the Instrument tab, or the
  `ch3_keyswitch` / `ch4_keyswitch` parameters),

and automate the same parameters `PARAMETERS.md` lists if you want the second half of
the tune to change as the Reaper version does. An `.flp` is not generated: the format
is binary and undocumented.

## Regenerating

```
python3 tools/demo/make_demo.py
python3 tools/demo/make_demo.py --paramdump build/chipboy_paramdump_artefacts/Release/chipboy_paramdump   # cross-check the parameter table
```
