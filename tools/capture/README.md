# Hardware capture tooling

Everything needed to measure a real DMG or CGB and turn the recording into the
constants the emulation's analog stage needs.

**Start with [`../../docs/CAPTURE_GUIDE.md`](../../docs/CAPTURE_GUIDE.md)** — the
step-by-step procedure. This file is just what each piece is.

| File | What it is |
|---|---|
| `chipboy_probe.asm` | The probe ROM. 83 takes, each preceded by a sync marker encoding its id. Measures **analog** properties only — digital behaviour is verified by blargg's `dmg_sound` and SameSuite (spec §16.1), which audio cannot do better. |
| `chipboy_probe.gb` | The built ROM, committed for convenience. Rebuild with `./build.sh` after any change to the `.asm`. |
| `build.sh` | `rgbasm` → `rgblink` → `rgbfix`. Needs [RGBDS](https://rgbds.gbdev.io). |
| `verify_rom.py` | Executes the ROM on a minimal SM83 interpreter and checks it produces the intended register sequence. **Run this after every rebuild.** Also emits `takes.json`. |
| `takes.json` | The take manifest, generated by `verify_rom.py`. The analyser reads it, so the ROM and the analyser cannot drift apart. |
| `make_calibration_wav.py` | Generates the loopback signal that characterises the interface itself. |
| `analyse.py` | Segments a capture by its markers and measures everything. Writes `<capture>_measured.json`. |
| `simulate_capture.py` | Synthesises a fake capture from known constants so `analyse.py` can be tested without hardware. |

## Testing the analyser without a Game Boy

```sh
python simulate_capture.py sim.wav
python make_calibration_wav.py cal.wav
python analyse.py sim.wav --loopback cal.wav
```

`sim_truth.json` holds the constants the simulator used. The analyser should recover
them: DAC slope and intercept, a zero crossing at level 7.5, and the coupling factor
per CPU cycle. Do this after any change to `analyse.py`.

Note the interpreter in `verify_rom.py` is a throwaway prototype of the M1 test-ROM
harness (spec §16.1) — it implements only the opcodes this ROM uses and raises on
anything else, which is what makes "it ran" mean "every instruction was understood".
It is not the real harness and ships in nothing.
